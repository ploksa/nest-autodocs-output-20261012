Nest does not talk to Express, Fastify, or any other HTTP server directly. Instead, it works through an adapter layer made of two contracts (`HttpServer` and `AbstractHttpAdapter`), a host object (`HttpAdapterHost`), and a loader (`loadAdapter`). Understanding this layer is the prerequisite for swapping platforms or writing a custom HTTP adapter.

## Source files

| File | Role |
| --- | --- |
| `packages/common/interfaces/http/http-server.interface.ts` | `HttpServer<TRequest, TResponse, ServerInstance>` interface. The minimal contract any adapter must satisfy. |
| `packages/core/adapters/http-adapter.ts` | `AbstractHttpAdapter<TServer, TRequest, TResponse>` abstract class. Implements `HttpServer` with default behavior and declares abstract platform-specific methods. |
| `packages/core/helpers/http-adapter-host.ts` | `HttpAdapterHost`. Mutable wrapper that holds the adapter reference and exposes lifecycle observables. |
| `packages/core/helpers/load-adapter.ts` | `loadAdapter`. Dynamic-import helper that loads the default platform package or exits on failure. |
| `packages/core/helpers/router-method-factory.ts` | `RouterMethodFactory`. Maps `RequestMethod` enum values to adapter method names such as `get`, `post`, etc. |
| `packages/core/nest-factory.ts` | `NestFactoryStatic`. Detects whether an adapter was passed and falls back to `createHttpAdapter`. |
| `packages/core/nest-application.ts` | `NestApplication`. Delegates `listen`, `init`, `enableCors`, `useStaticAssets`, and router registration to the adapter. |

## The HttpServer interface

The `HttpServer` interface in `packages/common/interfaces/http/http-server.interface.ts` is the smallest surface Nest expects from a platform. It lists HTTP verbs, lifecycle hooks, server control, and utility methods:

```ts packages/common/interfaces/http/http-server.interface.ts
export interface HttpServer<
  TRequest = any,
  TResponse = any,
  ServerInstance = any,
> {
  use(
    handler:
      | RequestHandler<TRequest, TResponse>
      | ErrorHandler<TRequest, TResponse>,
  ): any;
  use(
    path: string,
    handler:
      | RequestHandler<TRequest, TResponse>
      | ErrorHandler<TRequest, TResponse>,
  ): any;
  get(handler: RequestHandler<TRequest, TResponse>): any;
  get(path: string, handler: RequestHandler<TRequest, TResponse>): any;
  post(handler: RequestHandler<TRequest, TResponse>): any;
  post(path: string, handler: RequestHandler<TRequest, TResponse>): any;
  // ... put, patch, delete, head, options, all, etc.
  listen(port: number | string, callback?: () => void): any;
  listen(port: number | string, hostname: string, callback?: () => void): any;
  reply(response: any, body: any, statusCode?: number): any;
  status(response: any, statusCode: number): any;
  render(response: any, view: string, options: any): any;
  redirect(response: any, statusCode: number, url: string): any;
  isHeadersSent(response: any): boolean;
  setHeader(response: any, name: string, value: string): any;
  createMiddlewareFactory(
    method: RequestMethod,
  ):
    | ((path: string, callback: Function) => any)
    | Promise<(path: string, callback: Function) => any>;
  registerParserMiddleware(...args: any[]): any;
  enableCors(options: any): any;
  getHttpServer(): any;
  initHttpServer(options: NestApplicationOptions): void;
  close(): any;
  getType(): string;
  applyVersionFilter(
    handler: Function,
    version: VersionValue,
    versioningOptions: VersioningOptions,
  ): (req: TRequest, res: TResponse, next: () => void) => Function;
}
```

Optional methods (marked with `?`) include `setErrorHandler`, `setNotFoundHandler`, `useStaticAssets`, `setBaseViewsDir`, `setViewEngine`, `useBodyParser`, `beforeClose`, and `init`. An adapter is not required to implement these, but the core gracefully degrades when they are absent.

## AbstractHttpAdapter

`AbstractHttpAdapter` in `packages/core/adapters/http-adapter.ts` is the class every platform package extends. It stores:

- `protected httpServer: TServer` (the underlying Node.js `http.Server` or similar)
- `protected instance: any` (the platform application object, e.g., the Express app or Fastify instance)
- `protected onRouteTriggered` (a hook used internally for route tracing)

The class provides concrete implementations for all HTTP verbs by delegating to `this.instance`:

```ts packages/core/adapters/http-adapter.ts
export abstract class AbstractHttpAdapter<
  TServer = any, TRequest = any, TResponse = any,
> implements HttpServer<TRequest, TResponse> {
  public get(...args: any[]) { return this.instance.get(...args); }
  public post(...args: any[]) { return this.instance.post(...args); }
  public put(...args: any[]) { return this.instance.put(...args); }
  public patch(...args: any[]) { return this.instance.patch(...args); }
  public delete(...args: any[]) { return this.instance.delete(...args); }
  public head(...args: any[]) { return this.instance.head(...args); }
  public options(...args: any[]) { return this.instance.options(...args); }
  public all(...args: any[]) { return this.instance.all(...args); }
  public search(...args: any[]) { return this.instance.search(...args); }
  public query(...args: any[]) { return this.instance.query(...args); }
  public propfind(...args: any[]) { return this.instance.propfind(...args); }
  public proppatch(...args: any[]) { return this.instance.proppatch(...args); }
  public mkcol(...args: any[]) { return this.instance.mkcol(...args); }
  public copy(...args: any[]) { return this.instance.copy(...args); }
  public move(...args: any[]) { return this.instance.move(...args); }
  public lock(...args: any[]) { return this.instance.lock(...args); }
  public unlock(...args: any[]) { return this.instance.unlock(...args); }
  public listen(...args: any[]) { return this.instance.listen(...args); }
  // ...
}
```

It also implements `listen` by forwarding to `this.instance.listen`, and provides accessors such as `getHttpServer`, `setHttpServer`, `getInstance`, and `setInstance`.

What makes the class _abstract_ is the long list of methods that each platform must implement:

```ts packages/core/adapters/http-adapter.ts
abstract close();
abstract initHttpServer(options: NestApplicationOptions);
abstract useStaticAssets(...args: any[]);
abstract setViewEngine(engine: string);
abstract getRequestHostname(request: any);
abstract getRequestMethod(request: any);
abstract getRequestUrl(request: any);
abstract status(response: any, statusCode: number);
abstract reply(response: any, body: any, statusCode?: number);
abstract end(response: any, message?: string);
abstract render(response: any, view: string, options: any);
abstract redirect(response: any, statusCode: number, url: string);
abstract setErrorHandler(handler: Function, prefix?: string);
abstract setNotFoundHandler(handler: Function, prefix?: string);
abstract isHeadersSent(response: any);
abstract getHeader(response: any, name: string);
abstract setHeader(response: any, name: string, value: string);
abstract appendHeader(response: any, name: string, value: string);
abstract registerParserMiddleware(prefix?: string, rawBody?: boolean);
abstract enableCors(options?: any, prefix?: string);
abstract createMiddlewareFactory(requestMethod: RequestMethod):
  | ((path: string, callback: Function) => any)
  | Promise<(path: string, callback: Function) => any>;
abstract getType(): string;
abstract applyVersionFilter(
  handler: Function,
  version: VersionValue,
  versioningOptions: VersioningOptions,
): (req: TRequest, res: TResponse, next: () => void) => Function;
```

These abstract methods encode exactly how Nest asks the platform to perform tasks such as sending a response, enabling CORS, or registering body parsers.

## RouterMethodFactory

`RouterMethodFactory` in `packages/core/helpers/router-method-factory.ts` resolves the adapter method that matches a `RequestMethod` enum value:

```ts packages/core/helpers/router-method-factory.ts
export const REQUEST_METHOD_MAP = {
  [RequestMethod.GET]: 'get',
  [RequestMethod.POST]: 'post',
  [RequestMethod.PUT]: 'put',
  [RequestMethod.DELETE]: 'delete',
  [RequestMethod.PATCH]: 'patch',
  [RequestMethod.ALL]: 'all',
  [RequestMethod.OPTIONS]: 'options',
  [RequestMethod.HEAD]: 'head',
  [RequestMethod.SEARCH]: 'search',
  [RequestMethod.PROPFIND]: 'propfind',
  [RequestMethod.PROPPATCH]: 'proppatch',
  [RequestMethod.MKCOL]: 'mkcol',
  [RequestMethod.COPY]: 'copy',
  [RequestMethod.MOVE]: 'move',
  [RequestMethod.LOCK]: 'lock',
  [RequestMethod.UNLOCK]: 'unlock',
  [RequestMethod.QUERY]: 'query',
} as const satisfies Record<RequestMethod, keyof HttpServer>;

export class RouterMethodFactory {
  public get(target: HttpServer, requestMethod: RequestMethod): Function {
    const methodName = REQUEST_METHOD_MAP[requestMethod];
    const method = target[methodName];
    if (!method) {
      return target.use;
    }
    return method;
  }
}
```

If a platform does not support a rare method (for example, `mkcol`), the factory falls back to `target.use`, which keeps the router resilient.

## HttpAdapterHost

`HttpAdapterHost` in `packages/core/helpers/http-adapter-host.ts` is a mutable wrapper around the adapter instance. It is stored inside `NestContainer` so that other parts of the framework (middleware, routes, WebSocket modules) can retrieve the current adapter without reaching into `NestApplication`.

```ts packages/core/helpers/http-adapter-host.ts
export class HttpAdapterHost<
  T extends AbstractHttpAdapter = AbstractHttpAdapter,
> {
  private _httpAdapter?: T;
  private _listen$ = new Subject<void>();
  private _init$ = new ReplaySubject<void>();
  private isListening = false;

  set httpAdapter(httpAdapter: T) {
    this._httpAdapter = httpAdapter;
    this._init$.next();
    this._init$.complete();
  }
  get httpAdapter(): T { return this._httpAdapter as T; }

  get listen$(): Observable<void> {
    return this._listen$.asObservable();
  }
  get init$(): Observable<void> {
    return this._init$.asObservable();
  }

  set listening(listening: boolean) {
    this.isListening = listening;
    if (listening) {
      this._listen$.next();
      this._listen$.complete();
    }
  }
  get listening(): boolean {
    return this.isListening;
  }
}
```

Setting `httpAdapter` emits and completes `init$`. Setting `listening = true` emits and completes `listen$`. These observables are useful for hooks that need to react to adapter initialization or server startup.

## How NestFactory loads the default adapter

`NestFactoryStatic.create` in `packages/core/nest-factory.ts` decides whether the caller passed an adapter or just options:

```ts packages/core/nest-factory.ts
public async create<T extends INestApplication = INestApplication>(
  moduleCls: IEntryNestModule,
  serverOrOptions?: AbstractHttpAdapter | NestApplicationOptions,
  options?: NestApplicationOptions,
): Promise<T> {
  const [httpServer, appOptions] = this.isHttpServer(serverOrOptions!)
    ? [serverOrOptions, options]
    : [await this.createHttpAdapter(), serverOrOptions];
  // ...
}
```

`isHttpServer` does a duck-type check:

```ts packages/core/nest-factory.ts
private isHttpServer(
  serverOrOptions: AbstractHttpAdapter | NestApplicationOptions,
): serverOrOptions is AbstractHttpAdapter {
  return !!(serverOrOptions && (serverOrOptions as AbstractHttpAdapter).patch);
}
```

If no adapter is supplied, `createHttpAdapter` calls `loadAdapter`:

```ts packages/core/nest-factory.ts
private async createHttpAdapter<T = any>(httpServer?: T): Promise<AbstractHttpAdapter> {
  const { ExpressAdapter } = await loadAdapter(
    '@nestjs/platform-express',
    'HTTP',
    () => import('@nestjs/platform-express'),
  );
  return new ExpressAdapter(httpServer);
}
```

`loadAdapter` in `packages/core/helpers/load-adapter.ts` tries the import and fatally exits on failure:

```ts packages/core/helpers/load-adapter.ts
export async function loadAdapter(
  defaultPlatform: string,
  transport: string,
  loaderFn?: Function,
) {
  try {
    return loaderFn ? await loaderFn() : await import(defaultPlatform);
  } catch (e) {
    logger.error(MISSING_REQUIRED_DEPENDENCY(defaultPlatform, transport));
    process.exit(1);
  }
}
```

This is why `@nestjs/platform-express` must be installed unless you explicitly pass another adapter to `NestFactory.create`.

## How NestApplication delegates to the adapter

`NestApplication` in `packages/core/nest-application.ts` holds the adapter in its `httpAdapter` field and delegates critical work to it. The main lifecycle flow is:

<Steps>
  <Step title="Instantiation">
    In `NestApplication.createServer()`, it calls `this.httpAdapter.initHttpServer(this.appOptions)` and then `this.httpAdapter.getHttpServer()` to store the native server.
  </Step>
  <Step title="Init">
    `NestApplication.init()` calls `this.httpAdapter?.init?.()` (used by Fastify to register middie) and `this.registerParserMiddleware()`, which forwards to `this.httpAdapter.registerParserMiddleware(prefix, rawBody)`.
  </Step>
  <Step title="Router registration">
    `registerRouter()` calls `this.routesResolver.resolve(this.httpAdapter, basePath)`. Before that, it registers middleware through `this.middlewareModule.register(...)`, which in turn calls `adapter.createMiddlewareFactory(requestMethod)` to mount middleware on the correct HTTP verb.
  </Step>
  <Step title="Hooks">
    `registerRouterHooks()` asks the adapter to mount the 404 and exception handlers: `this.routesResolver.registerNotFoundHandler()` and `registerExceptionHandler()`, which internally call `adapter.setNotFoundHandler(...)` and `adapter.setErrorHandler(...)`.
  </Step>
  <Step title="Listen">
    `listen()` lazily calls `init()` if needed, then delegates to `this.httpAdapter.listen(port, ...listenFnArgs, callback)`.
  </Step>
</Steps>

Many convenience methods on `NestApplication` are thin wrappers:

```ts packages/core/nest-application.ts
public enableCors(options?: any): void {
  this.httpAdapter.enableCors(options);
}

public useStaticAssets(pathOrOptions: any, options?: any): this {
  this.httpAdapter.useStaticAssets?.(pathOrOptions, options);
  return this;
}
```

If the adapter does not implement an optional method (such as `useStaticAssets`), the call is silently skipped.

## Adapter proxy on the returned application

After constructing `NestApplication`, `NestFactoryStatic.create` wraps it with `createAdapterProxy`:

```ts packages/core/nest-factory.ts
private createAdapterProxy<T>(app: NestApplication, adapter: HttpServer): T {
  const proxy = new Proxy(app, {
    get: (receiver: Record<string, any>, prop: string) => {
      const mapToProxy = (result: unknown) => {
        return result instanceof Promise
          ? result.then(mapToProxy)
          : result instanceof NestApplication
            ? proxy
            : result;
      };

      if (!(prop in receiver) && prop in adapter) {
        return (...args: unknown[]) => {
          const result = this.createExceptionZone(adapter, prop)(...args);
          return mapToProxy(result);
        };
      }
      if (isFunction(receiver[prop])) {
        return (...args: unknown[]) => {
          const result = receiver[prop](...args);
          return mapToProxy(result);
        };
      }
      return receiver[prop];
    },
  });
  return proxy as unknown as T;
}
```

This proxy is what makes `app.set(...)` work for Express even though `set` is not defined on `NestApplication`. If the property exists on the adapter but not on `NestApplication`, the proxy forwards the call to the adapter. The result is re-wrapped so that chaining still returns the proxied application.

## Writing a custom HTTP adapter

To create a custom adapter you extend `AbstractHttpAdapter` and implement every abstract method. The minimum viable adapter only needs to satisfy the HTTP verb delegation already provided by the base class, plus the abstract methods. A simplified example that wraps a custom server might look like this:

```ts
import { AbstractHttpAdapter } from '@nestjs/core';
import { RequestMethod, VersioningOptions, VersionValue } from '@nestjs/common';
import { createServer, Server } from 'http';
import { isNil, isObject } from '@nestjs/common/internal';

class CustomAdapter extends AbstractHttpAdapter<Server> {
  getType(): string { return 'custom'; }

  initHttpServer(options: any) {
    this.httpServer = createServer(this.instance);
  }

  close() {
    return new Promise<void>((resolve) => this.httpServer.close(() => resolve()));
  }

  useStaticAssets(...args: any[]) { /* no-op */ }
  setViewEngine(engine: string) { /* no-op */ }

  getRequestHostname(request: any) { return request.headers.host; }
  getRequestMethod(request: any) { return request.method; }
  getRequestUrl(request: any) { return request.url; }

  status(response: any, statusCode: number) {
    response.statusCode = statusCode;
    return response;
  }
  reply(response: any, body: any, statusCode?: number) {
    if (!isNil(statusCode)) response.statusCode = statusCode;
    response.end(typeof body === 'string' ? body : JSON.stringify(body));
    return response;
  }
  end(response: any, message?: string) { return response.end(message); }
  render(response: any, view: string, options: any) { /* no-op */ }
  redirect(response: any, statusCode: number, url: string) {
    response.statusCode = statusCode;
    response.setHeader('Location', url);
    response.end();
  }

  setErrorHandler(handler: Function, prefix?: string) { /* no-op */ }
  setNotFoundHandler(handler: Function, prefix?: string) { /* no-op */ }
  isHeadersSent(response: any) { return response.writableEnded; }
  getHeader(response: any, name: string) { return response.getHeader(name); }
  setHeader(response: any, name: string, value: string) {
    return response.setHeader(name, value);
  }
  appendHeader(response: any, name: string, value: string) {
    const current = response.getHeader(name);
    if (!current) return this.setHeader(response, name, value);
    return response.setHeader(name, Array.isArray(current) ? [...current, value] : [current, value]);
  }

  registerParserMiddleware(prefix?: string, rawBody?: boolean) { /* no-op */ }
  enableCors(options?: any, prefix?: string) { /* no-op */ }

  createMiddlewareFactory(requestMethod: RequestMethod) {
    return (path: string, callback: Function) => {
      this.instance.use(path, callback);
    };
  }

  applyVersionFilter(
    handler: Function,
    version: VersionValue,
    versioningOptions: VersioningOptions,
  ) {
    return (req: any, res: any, next: () => void) => handler(req, res, next);
  }
}
```

Register it by passing an instance to `NestFactory.create`:

```ts
const app = await NestFactory.create(AppModule, new CustomAdapter());
await app.listen(3000);
```

Because `NestFactory.create` detects the adapter via the `patch` property (duck typing), any class that inherits from `AbstractHttpAdapter` is accepted.

<Note>
  When you write a custom adapter, make sure `createMiddlewareFactory` returns a function that accepts `(path, callback)`. The middleware module calls this factory for each HTTP method and uses the returned function to mount middleware.
</Note>
